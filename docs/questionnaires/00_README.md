# Questionnaires — how to answer

Questions only the maintainer can answer. One file per moment of the work, newest last; each says why a question matters and gives a recommended answer.

**Answer format**
- Write after `A:` on each question; `[x]` marks a choice; `UNKNOWN`, `NOT APPLICABLE` and `LATER` are valid; "Recommended" accepts my suggestion.
- Never write passwords, tokens or secrets. Write *where* they live, not their values.

When you finish one, tell me which and I will write the answers into the tasks, the ADRs and the documents they change (the documentation rule of `../../CLAUDE.md`).
