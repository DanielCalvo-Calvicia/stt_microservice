## Goal

Make the script download the main local model when the engine is not `openai`, and the gate's model when the gate is on, with the same threads and compute type the service will use. Natively, a deploy then leaves every model in the cache before the service starts (debt 3, NFR-9 for the native path).

## Specification

- Models to load, in this order: the main model (`cfg.model`) when `cfg.engine != "openai"`; the gate (`cfg.gate_model`) when `cfg.gate_enabled`. A name already loaded in this run (main and gate the same) is loaded once.
- Each load uses `device="cpu"`, `compute_type=cfg.compute_type`, `cpu_threads=cfg.threads` (the same arguments as the service).
- If one load fails, print the error to stderr, **still try the others**, and exit 1 at the end; exit 0 when every needed model loaded or none is needed. Messages name the role (`main` or `gate`) and the model. No new exit code.
- The docstring says what it needs: the settings come from the environment or the `.env` next to `main.py`, so a Docker build (which has neither) fetches nothing and the models must be fetched at run time (T-02.3).
- Do not import `faster_whisper` at module level (the tests rely on the late import) and do not log or print any key.

## Acceptance criteria

- New tests: engine `openai` and gate off → nothing loaded, exit 0; engine `local` → main model loaded with the configured model, threads and compute type; engine `local` and gate on → both, in order; the main model fails and the gate succeeds → exit 1 and the gate was still tried; main and gate the same name → one load.
- The suite passes with the new total, recorded in `README.md` and `CLAUDE.md`.
- A real run, with the maintainer's yes (it downloads about the size of `small.en`, hundreds of MB): `windows\Scripts\python.exe scripts\fetch_gate_model.py` with `STT_ENGINE=local` and a throw-away `HF_HOME` prints the main model ready and exits 0; a second run downloads nothing. Note the cache size in *Notes*.

## Verification

`windows\Scripts\python.exe -m pytest tests\scripts`, the whole suite, and the real run above (pasted: the printed lines, the exit code, the cache folder size).
