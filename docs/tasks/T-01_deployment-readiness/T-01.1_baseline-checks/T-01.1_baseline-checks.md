## Goal

Find out what a fresh deploy of stt really does today, before changing anything. No code is changed in this group: each leaf writes what it found in its *Notes*, and anything that contradicts [../../../deployment_audit/stt.md](../../../deployment_audit/stt.md) or the documents is corrected there (T-04).

## Why before the fixes

The working folder already has a populated venv, a real `.env`, a Hugging Face cache on the maintainer's machine and uncommitted `contracts` edits (F1), so it proves nothing about a fresh machine. A clean clone and the deployment tool prove the path a real deploy takes. The first-start time of a local model (download plus load) is the number that is attached to ADR-009 (the Docker half is decided: option B).
