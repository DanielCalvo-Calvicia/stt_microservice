## Goal

Make the model, the thread count and the compute type of the local engine settings instead of constants, with today's values as the defaults, and make the gate use the same threads and compute type (debt 1, FR-8). Today `STT_LANGUAGE=es` cannot work with the local engine because the main model is always `small.en` (F4), and a Raspberry Pi cannot be tuned without editing code.

## Exit criteria

With no new variable set, the service behaves exactly as before (`small.en`, `int8`, 2 threads, the gate's `tiny.en`); with them set, the values reach `WhisperModel` for both the main model and the gate; a bad value fails at start with a message that names the variable (or is handled as the decision says); `.env.example`, the configuration documents and the generated deployment settings file list them.
