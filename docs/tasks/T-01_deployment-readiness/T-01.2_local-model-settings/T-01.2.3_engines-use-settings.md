## Specification

- The device stays `"cpu"`. The decoding options (`beam_size`, `condition_on_previous_text`, `no_speech_threshold`) are unchanged.
- The log message `Loading local Whisper model on CPU with int8 compute` says `int8`, which stops being a constant: change it to a constant string without the compute type (`Loading local Whisper model on CPU`) and put `model_name`, `compute_type` and `cpu_threads` in keyword fields. `monitoring.md` already names `Loading local Whisper model on CPU`; make the document match the final text.
- Tests, all with a fake `WhisperModel` (no download): the default call is `("small.en", device="cpu", compute_type="int8", cpu_threads=2)`; given values are passed through; `new_http_container` with `STT_ENGINE=local`, `STT_MODEL`, `STT_THREADS`, `STT_COMPUTE_TYPE` and the gate on loads the main model and the gate with the shared threads and compute type and their own model names.
- Do not change the OpenAI engine, the ports or the routes.
